Code walkthrough prep · PR #5150 · Analytics Governance tab

Questions that expose the real gaps

Use these as demo prompts, not a line-by-line interrogation. The highest-signal checks are URL/filter behavior, independently failing queries, and a connector with 51+ child profiles.

Start here Demo the risky paths

  1. Can we set a date range and filters, switch Analytics ↔ Govern, then refresh and share the URL?Catches filter loss, broken deep links, and tab state that is not preserved.
  2. Can we demo a connector with more than 50 profiles or children?Ask what users see when children_truncated is true. Profiles must not silently disappear.
  3. What happens when the leaderboard, usage banner, and governance list each fail independently?Verify visible error and retry states. “No connectors found” must never mask an API failure.
  4. When I click “View all” from Most errored or Slowest, what tells the user why the destination table is ordered that way?The active sort must be visible and match the backend query, or the result looks arbitrary.

Metric and API-contract questions

  1. What does “completion rate” mean exactly: tool-call success, connector auth success, or an agent workflow completing?The generated contract describes tool success rate. Confirm the UI label does not overpromise.
  2. Which API fields are authoritative, and which are best-effort or unavailable?Probe cost, latency, profile attribution, and zero traffic. Missing data needs to be distinguishable from a true zero.
  3. How are percentage metrics formatted and tested for whole-number values such as 100?Formatting must follow the metric type, not whether a number happens to have a fractional part.
  4. What prevents the analytics and governance adapters from drifting as the API evolves?Look for generated-contract use, adapter/contract tests, and a named owner.

Scale, architecture, and readiness

  1. What is the expected experience for 10 connectors with hundreds of child profiles?Probe payload size, pagination, row virtualization, and whether inline child rows make the table unusable.
  2. Why does Analytics depend on Governance feature types?If the sort concepts are shared, they should live in a shared/domain layer rather than creating feature-to-feature coupling.
  3. What UI-level behavior is covered by tests?Ask specifically about tab/query preservation, error recovery, truncation, empty versus failed states, and every leaderboard “View all” link.
Walkthrough exit criteria
  • Filters survive tab changes, refresh, and a copied URL.
  • Errors are distinct from empty data and can recover without remounting.
  • 51+ child profiles have an explicit, complete user path.
  • Metric labels, units, and API semantics agree.
  • The destination state of every “View all” link is visible and explainable.
